# Minecraft 1.21.1 Adaptation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 Fast Masa Config 从 `mc/1.21.7` 基线适配为 Minecraft 1.21.1，并推送独立分支。

**Architecture:** 保留 `main` 的 Minecraft 26.1.2 实现不变，在 `mc/1.21.1` 分支中只调整构建配置、mod metadata 和必要的 API 调用。Tweakeroo、Litematica、MaLiLib 上游仓库只用于确认 MaLiLib API 与兼容依赖，不作为源码依赖引入。

**Tech Stack:** Java 21, Gradle Wrapper, Fabric Loom, Fabric Loader, Fabric API, MaLiLib, Mod Menu。

---

### Task 1: 锁定 1.21.1 构建版本

**Files:**
- Modify: `gradle.properties`
- Modify: `src/main/resources/fabric.mod.json`

- [ ] **Step 1: 将 Gradle 版本属性切换为 1.21.1 兼容组合**

将 `minecraft_version`、mappings、Loader、Fabric API、MaLiLib 和 Mod Menu 设置为经构建验证的 1.21.1 版本，并将 Java toolchain/compile release 与 Minecraft 1.21.x 要求保持一致。

- [ ] **Step 2: 同步 fabric.mod.json 约束**

将 `minecraft` 约束改为 `~1.21.1`，Java 约束改为 `>=21`，MaLiLib 约束与选定版本的主版本范围一致。

- [ ] **Step 3: 执行依赖解析与测试编译**

运行 `./gradlew.bat test`，记录首个真实编译错误；如果没有错误，继续执行构建。

### Task 2: 修复 1.21.1 API 编译差异

**Files:**
- Modify: 由 Task 1 编译错误直接指向的 `src/main/java/**` 或 `src/client/java/**` 文件
- Test: 现有 `src/test/java/**` 中与修改逻辑对应的测试

- [ ] **Step 1: 按错误位置确认调用方和上游 API**

只对 1.21.1 编译失败的调用点进行修改，保持现有快捷面板、配置扫描和按键行为不变。

- [ ] **Step 2: 运行相关测试**

运行 `./gradlew.bat test`，确认单元测试和 Java 编译通过。

- [ ] **Step 3: 运行完整构建**

运行 `./gradlew.bat build`，确认 remap、资源处理和 jar 产物生成成功。

### Task 3: 检查产物并推送分支

**Files:**
- No source changes expected

- [ ] **Step 1: 检查版本元数据和产物**

确认 `build/libs/` 中有 remapped jar，且生成的 `fabric.mod.json` 使用 1.21.1 约束。

- [ ] **Step 2: 检查工作区和提交内容**

运行 `git status --short --branch`、`git diff --check` 和 `git diff --stat`，确认没有构建缓存或运行目录被纳入提交。

- [ ] **Step 3: 提交适配变更**

使用提交信息 `build: add Minecraft 1.21.1 compatibility branch` 提交适配内容。

- [ ] **Step 4: 推送新分支并复核远端**

运行 `git push -u origin mc/1.21.1`，再用 `git ls-remote --heads origin mc/1.21.1` 核对远端分支指向本地提交。
