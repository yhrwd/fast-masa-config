# 1.21.1 Main UI Fidelity Design

## Goal

在 `mc/1.21.1` 分支中，以 `main` 的 Minecraft 26.1.2 配置页为唯一界面和交互基准，恢复 Generic、Shortcuts 和 All Configs 三页的行为。热键录入和高级热键设置必须由 MaLiLib 0.21.10 的原生组件和状态机处理。

## Scope

- 保留 `FastMasaConfigGui` 的三分页、搜索、筛选、快捷项维护、数值滑条、布尔开关和模组切换行为，并逐项对照 `main` 的实现。
- 删除 1.21.1 分支中仅为模拟控件而存在的交互分歧；无法使用新版 API 的位置改为调用 MaLiLib 0.21.10 的等价 API。
- 快捷键录入使用 `ConfigButtonKeybind` 的完整选择、鼠标按键、键盘按键、清除、冲突提示和配置持久化流程。
- 高级热键设置使用 `GuiKeybindSettings`，关闭后回到 `FastMasaConfigGui` 并刷新按键显示及 MaLiLib 已占用按键映射。
- 不恢复旧版 `GuiConfigsBase` 列表页面。它能提供完整的 MaLiLib 通用配置页，但视觉和分页交互不符合 26.1.2。

## Architecture

`FastMasaConfigGui` 继续作为页面状态和自绘列表的入口，保持与 `main` 相同的分页状态、筛选状态、滚动状态及 `ConfigIndexService` 数据来源。

MaLiLib 负责其已有领域：`ConfigButtonKeybind` 管理按键收集，`IKeybindConfigGui` 提供选择状态和显示刷新回调，`GuiKeybindSettings` 编辑 `KeybindSettings`，`InputEventHandler` 在变更后更新按键映射。页面不再尝试重写这些状态机。

输入顺序为：MaLiLib 控件先处理鼠标和普通输入；当热键按钮处于选择状态时，将键盘事件和鼠标按键交给该按钮；完成、取消或打开高级设置后，调用配置保存、`updateUsedKeys()` 和显示刷新。快捷面板的运行时热键回调继续保留在 `FastMasaInputHandler`。

## Error Handling

配置扫描失败维持现有的单个来源隔离，不影响配置页其余内容。无法解析的快捷项继续在 Shortcuts 页显示为缺失项，不自动删除持久化数据。MaLiLib 控件创建或配置页注册失败时记录已有警告并保留可打开的本页。

## Verification

- 为热键选择状态、取消/清除、设置保存后按键映射刷新补充针对性测试。
- 执行 `./gradlew.bat test` 和 `./gradlew.bat build`。
- 在 `run/version/1.21` 手动验证：三分页、搜索和筛选、配置值修改、快捷项维护、键盘/鼠标热键录入、高级设置弹窗、热键冲突提示，以及快捷面板开关。
