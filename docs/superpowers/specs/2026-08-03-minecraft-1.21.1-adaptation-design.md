# Minecraft 1.21.1 适配设计

## 目标

在不改变 `main` 当前 Minecraft 26.1.2 版本的前提下，为 Fast Masa Config 建立并维护一个可构建、可发布的 Minecraft 1.21.1 分支 `mc/1.21.1`。

## 方案

新分支从已有 `mc/1.21.7` 基线创建。三个上游仓库仅作为依赖版本和 MaLiLib API 的参考来源，不复制源码，也不改变本项目的模块边界。

版本配置将统一指向 Minecraft 1.21.1、Java 21、对应 Fabric Loader/Fabric API、Mod Menu 和 MaLiLib 版本。`fabric.mod.json` 的 Minecraft、Java 和 MaLiLib 约束必须与 Gradle 配置一致。

如果初次构建出现 API 不兼容，只修改 Fast Masa Config 中对应的调用点，并优先采用 1.21.x 基线已有的实现方式；不进行与适配无关的重构。

## 验证

使用项目 Gradle Wrapper 执行测试和构建，确认 Java 编译、资源处理、Fabric remap 和产物生成均成功。检查生成的 mod metadata 与目标版本一致，并确认工作区干净后推送 `mc/1.21.1` 到 `origin`。
