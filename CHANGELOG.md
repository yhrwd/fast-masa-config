# Changelog / 更新日志

## 5.4.0 — 2026-10-31

Available for Minecraft 26.1.2, 26.2, and 26.3.

### English

- Resize floating configuration and quick-message windows by dragging either the left or right edge. The opposite edge stays fixed, and each group remembers its own width after closing the panel or restarting the game.
- Show a horizontal resize cursor and highlight the active edge when hovering or dragging. Widths stay within the screen and cannot shrink below the minimum usable size.
- Wider windows give long option names more room, making English configurations easier to find at a glance. Thanks to PINPAL for [the suggestion and mock-up (#2)](https://github.com/yhrwd/fast-masa-config/issues/2).
- Update the mod icon and change the default floating-menu accent to `#488796`.
- Existing layouts and saved colors are preserved. Reset the floating-menu theme color to use the new default.

### 中文

- 配置分组和快捷消息浮窗均支持拖动左、右边缘调整宽度；另一侧保持固定，每个分组独立记忆宽度，关闭面板或重启游戏后仍保留。
- 悬停或拖动边缘时显示横向双箭头光标并高亮边缘；调整宽度时限制屏幕边界和最小可用宽度。
- 拉宽窗口后，较长的配置名称有更多显示空间，英文配置更容易快速查找。感谢 PINPAL 提供[建议和交互示意图（#2）](https://github.com/yhrwd/fast-masa-config/issues/2)。
- 更新模组图标，默认悬浮菜单主题色改为 `#488796`。
- 兼容已有布局并保留已保存的颜色；需要使用新默认配色时，点击悬浮菜单主题色的“重置”。
